# Program-CPlusPlus-Tarif-Parkir-
Program C++ sederhana untuk menghitung tarif parkir berdasarkan jenis kendaraan, yaitu mobil atau motor, dan lama parkir. Program ini menggunakan variabel, input-output, percabangan if-else, serta operasi aritmetika untuk menghitung total biaya parkir dan biaya tambahan jika kendaraan parkir lebih dari 5 jam.
